# CrazyGames cover art

Generated for **Bloomtail: Color Trail** from the game's own vector shapes.

| File | Size | Use |
| --- | --- | --- |
| `cover-1920x1080.png` | 1920×1080 | Landscape cover |
| `cover-800x1200.png` | 800×1200 | Portrait cover |
| `cover-800x800.png` | 800×800 | Square cover |

The title is set in **Baloo 2 ExtraBold** (SIL Open Font License 1.1,
https://fonts.google.com/specimen/Baloo+2). The rest of the art is original
project work. The covers contain no gameplay screenshots and no borders.

These are press assets only; they are not part of the game bundle.
